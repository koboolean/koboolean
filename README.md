# 👋 About Me

안녕하세요! 저는 **문제 해결을 넘어 더 나은 서비스를 만드는 개발자** 조현준입니다.
백엔드 개발을 중심으로 다양한 기술을 학습하고 활용하며, **효율적이고 확장 가능한 시스템**을 구축하는 것에 관심이 많습니다.

다양한 프로젝트를 수행하며 **서비스 안정성과 성능 최적화, 유지보수성 향상**을 위해 노력하고 있습니다.
현재는 **Spring 기반 백엔드 개발**과 **DevOps, 프론트엔드 기술**까지 폭넓게 다루며, 보다 나은 사용자 경험을 제공하기 위해 끊임없이 연구하고 있습니다.
